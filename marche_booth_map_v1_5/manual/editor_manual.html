Marche Booth Map v1.5 編集者マニュアル

イベント主催者・マップ作成者向けの編集手順です。v1.5では、v1.2のブース・設備・通路GUI編集に加えて、直接リサイズ、複数ブース選択、整列・等間隔配置、行列ブース一括生成に対応しました。

v1.5のポイント：会場図作成時に座標を1件ずつ入力する作業を減らし、マウス操作と一括配置で短時間にレイアウトを作れるようにしています。

1. 起動方法

Windows: start_editor.bat をダブルクリックします。PythonのローカルHTTPサーバーが起動し、http://localhost:8000/editor.html が開きます。

HTMLを直接ダブルクリックするとJSONの読み込みがブラウザに制限される場合があるため、BATから起動してください。

3. 基本のオブジェクト操作

操作動作

右下の小さい四角をドラッグ選択物の幅・高さを直接変更

直接リサイズはブース・設備・通路に対応しています。選択したオブジェクトの右下に表示されるハンドルをドラッグしてください。

4. ブースを1件ずつ作る

  1. 「□ ブース」を押します。
  2. 新規ブースが会場左上付近へ追加されます。
  3. ドラッグして配置し、右下ハンドルで大きさを調整します。
  4. 必要ならX/Y/幅/高さを数値入力します。
  5. 「新しい番号」を入力し「番号変更」でA01などに変更します。

ブース番号変更時は、そのブースに紐づく出店者の booth_id も連動変更します。

5. 行列ブースを一括生成する

左側の「ブース一括生成」で、同じ大きさのブースを行×列でまとめて作れます。

項目意味初期値
接頭辞ブース番号の先頭文字。CならC01、C02…C
開始番号最初に使用する番号1
行数 / 列数生成する行・列。各1～302 / 4
ブース幅 / 高さ各ブースのSVG上のサイズ130 / 95
横間隔 / 縦間隔ブース間の空き20 / 25
開始X / Y左上ブースを置く開始座標100 / 100
  1. 各値を入力します。
  2. 「行列を生成」を押します。
  3. 生成されたブースはすべて複数選択状態になります。
  4. そのままドラッグしてブロック全体を好きな位置へ移動できます。

既存ブース番号と重複する場合は、重複しない次の番号を自動的に探します。

6. 複数ブースを選択する

Ctrl（macOSでは⌘）を押しながらブースをクリックすると、選択へ追加・解除できます。「全ブース選択」も利用できます。

複数選択中に選択ブースをドラッグすると、選択されたブースすべてをまとめて移動します。矢印キーによる移動もまとめて適用されます。

設備・通路は単一選択です。複数選択と整列機能はブースを対象にしています。

7. ブースを整列・等間隔配置する

2件以上のブースを複数選択すると、中央下部の「複数ブース整列」を使用できます。

ボタン動作
左揃え / 右揃え選択ブースの左右端を揃える
左右中央選択範囲の中央線へ各ブース中心を揃える
上揃え / 下揃え選択ブースの上下端を揃える
上下中央選択範囲の中央線へ各ブース中心を揃える
横に等間隔 / 縦に等間隔3件以上を中心位置基準で等間隔に並べる
同じサイズ選択中の主ブースと同じ幅・高さへ統一する

8. 設備と通路を作る

配置パレットから入口・受付・WC・休憩所・通路を追加できます。追加後はドラッグ移動、右下ハンドルで直接リサイズ、右側フォームで数値調整、複製・削除ができます。

横通路は幅を大きく・高さを小さく、縦通路は幅を小さく・高さを大きくすると作りやすいです。

9. 出店者情報を編集する

ブースを選択して右側の出店者編集フォームを入力します。ショップ名、カテゴリ、検索キーワード、説明、Instagram URL、ショップURL、メモを登録できます。

カテゴリと検索キーワードは「ドール, アクセサリー」のようにカンマ区切りで入力します。

10. 自動保存

編集中データはブラウザのlocalStorageへ自動保存されます。「自動保存を復元」から復元できます。

自動保存はバックアップです。公開用データは必ずJSONとして保存してください。バージョンごとに保存キーは分離されています。

11. JSONを書き出す

上部の「venue.json保存」「exhibitors.json保存」または「両方保存」を使用します。ダウンロードしたファイルをプロジェクトの data/venue.json と data/exhibitors.json へ上書きします。

12. GitHub Pagesへ反映する

  1. 編集画面からJSONを保存します。
  2. data/ 内のJSONを置き換えます。
  3. start_local_server.bat で閲覧画面を確認します。
  4. Gitでcommit/pushします。
  5. GitHub Pagesの公開URLを確認します。

13. データ形式

venue.json はイベント、viewBox、設備、通路、ブースを保持します。exhibitors.json は出店者情報を保持し、booth_id でブースに紐づきます。

{
  "id": "A01",
  "x": 235,
  "y": 165,
  "width": 130,
  "height": 95
}

会場サイズの変更（v1.5）

編集画面の「会場サイズ」から、会場幅・会場高さ・開始X・開始Yを変更できます。小 1000×700、中 1600×1000、大 2200×1400 のプリセットも利用できます。

  • 会場サイズを適用：入力値をviewBoxへ反映します。
  • 配置物に自動フィット：ブース・設備・通路を囲む最小範囲へ会場を調整します。余白も指定できます。
  • 端で自動拡張：ONの場合、配置物を会場端へドラッグすると100単位を目安に自動で会場を広げます。

会場サイズは画像ピクセル数ではなくSVG内部座標です。SVGのため会場を広げても図形自体の画質は劣化しません。
