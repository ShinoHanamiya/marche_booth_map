# Marche Booth Map v1.5

1つのマルシェ会場内の出店者を、SVG会場マップと一覧から探せる静的Webアプリです。
v1.5ではView側の「お気に入り」を当日の巡回管理に使えるよう強化しました。Edit側はv1.4の機能を維持しています。

## v1.5 主な追加機能
- 「♡ 行きたい」と「✓ 行った」の2状態管理
- `すべて / 行きたい / 未訪問 / 行った` の表示切替
- 行きたい件数・訪問済み件数をヘッダー表示
- 一覧からワンタップで「行きたい」「行った」を切替
- 詳細画面からも両状態を変更可能
- マップ上に ♥ / ✓ を表示
- 訪問済みブースを専用スタイルで強調
- 「未訪問」モードで、行きたいがまだ回っていないブースだけを一覧・マップ表示
- 状態をブラウザlocalStorageへ保存
- v1.4以前の「行きたい」localStorageをv1.5へ自動移行

## 閲覧画面の基本機能
- SVG会場マップ
- ブースクリック/タップで出店者詳細
- キーワード検索
- カテゴリ絞り込み
- 検索結果とマップの連動
- ズーム / パン / ピンチ操作
- Instagram・ショップへの外部リンク
- PC / スマホ対応

## 編集画面
v1.4までの会場編集機能を維持しています。
- ブース、入口、受付、WC、休憩所、通路のGUI配置
- ドラッグ移動・直接リサイズ
- 複数選択、整列、等間隔、サイズ統一
- 行列ブース一括生成
- 会場サイズGUI変更、プリセット、自動フィット、自動拡張
- 出店者情報編集
- JSON読込・書出
- 自動保存・データ確認

## 起動方法
### 閲覧画面
`start_local_server.bat` をダブルクリックし、`http://localhost:8000/` を開きます。

### 編集画面
`start_editor.bat` をダブルクリックし、`http://localhost:8000/editor.html` を開きます。

JSONをfetchするため、HTMLファイルの直接ダブルクリックではなくローカルHTTPサーバーを利用してください。

## 保存される個人状態
閲覧者の「行きたい」「行った」はJSONへは書き込まず、各ブラウザのlocalStorageへ保存します。そのため公開データを変更せず、来場者ごとに別々の状態を持てます。

- `marche_booth_map_favorites`: 行きたいブースID
- `marche_booth_map_visited`: 訪問済みブースID

別端末・別ブラウザ間では同期されません。
