Marche Booth Map v1.6 閲覧者マニュアル

マルシェ会場で出店者を検索し、ブース位置を確認しながら「行きたい」「行った」を管理するための閲覧者向けマニュアルです。

1. 基本の使い方

  1. 検索欄に作家名、商品名、ブース番号などを入力します。
  2. カテゴリボタンで出店ジャンルを絞り込めます。
  3. 一覧の「マップで見る」を押すと対象ブースへ移動します。
  4. 会場マップ上のブースをタップしても詳細を開けます。

2. 「行きたい」に登録する

一覧の ♡ または出店者詳細の「♡ 行きたい」を押すと登録されます。登録後は ♥ になり、マップ上でもブースが強調されます。

もう一度押すと解除できます。

3. 「行った」を記録する

訪問したブースは一覧の ○、または詳細画面の「○ 行ったにする」を押します。訪問済みになると ✓ で表示されます。

押し間違えた場合は、もう一度押すと未訪問へ戻せます。

4. お気に入り表示を切り替える

検索欄の下に4つの表示モードがあります。

  • すべて：全出店者
  • ♡ 行きたい：「行きたい」に登録した出店者
  • 未訪問：「行きたい」かつ、まだ「行った」にしていない出店者
  • ✓ 行った：訪問済みの出店者
イベント中は「未訪問」を表示しておくと、これから回りたいブースだけを自分用の攻略マップとして確認できます。

5. 件数表示

画面上部に「♡ 行きたい」と「✓ 行った」の件数が表示されます。当日の進み具合をすぐ確認できます。

6. マップ上の表示

  • 行きたい：強調枠＋♥
  • 行った：緑系の強調＋✓
  • 検索・絞り込み対象：対象ブースを強調し、それ以外を薄く表示
  • 選択中：さらに強い枠で表示

7. 保存について

「行きたい」「行った」の情報は、その端末・ブラウザの localStorage に保存されます。ページを閉じても同じブラウザから開けば残ります。

別のスマートフォンや別ブラウザには自動同期されません。ブラウザのサイトデータを削除すると記録も消えます。

8. マップ操作

  • PC：ドラッグで移動、マウスホイールで拡大・縮小
  • スマホ：指でドラッグ、ピンチで拡大・縮小
  • ＋ / −：拡大・縮小
  • ⌂：全体表示へ戻す

9. おすすめの当日利用

  1. 会場へ行く前に気になる出店者を「行きたい」に登録
  2. 会場では「未訪問」表示に切り替える
  3. 訪問したら「行った」に変更
  4. 残りの未訪問ブースを確認しながら巡る
  5. 最後に「行った」一覧から訪れた出店者を見返す

Instagramが複数あるブース

複数のInstagramアカウントが登録されているブースでは、詳細画面に「Instagram @アカウント名」のリンクが複数表示されます。目的のアカウントを選んで開いてください。
