Marche Booth Map v1.11 編集者マニュアル

複数マルシェの管理と、各会場レイアウト・出店者情報の編集方法を説明します。

公開時の注意：本アプリは有志が作成した非商用アプリです。掲載しているお店情報・リンク等には誤りや変更が含まれる場合があります。最新・正確な情報は各出店者・主催者の公式情報をご確認ください。

1. 起動方法

start_editor.bat をダブルクリックします。通常は http://localhost:8000/event_manager.html が開きます。

JSONを読み込むため、HTMLファイルの直接ダブルクリックではなくローカルHTTPサーバーから利用してください。

2. v1.11の編集フロー

  1. イベント管理画面を開く
  2. プロジェクトフォルダを接続する（推奨）
  3. イベントを新規作成・複製・選択する
  4. イベント情報を編集する
  5. 「会場レイアウト編集」からEditorを開く
  6. ブース・設備・出店者を編集する
  7. ローカル表示を確認する
  8. GitHubへcommit / pushする

3. プロジェクトフォルダ接続

Chrome / Edgeでは、イベント管理画面の「プロジェクトフォルダを接続」からローカルファイルへ直接保存できます。

  1. ボタンを押します。
  2. 展開した marche_booth_map_v1_11 フォルダそのものを選択します。
  3. ブラウザのアクセス許可を承認します。
  4. 表示が「接続中」になれば完了です。
対応していないブラウザではJSONダウンロード方式を利用できます。GitHub Pages上のファイルを直接書き換える機能ではありません。編集対象はユーザーが選択したローカルフォルダです。

4. 新規イベント

「＋ 新規イベント」を押し、イベントID・イベント名・作成方法を指定します。

項目説明
イベントIDフォルダ名・URLに使用します。半角英数字、_、-を使用してください。
空の会場から作成1000×700の基本会場と入口のみを作成します。
会場テンプレートから作成登録済みの会場レイアウトを使って新規イベントを作成します。出店者情報は空で開始します。
選択中イベントを複製event.json、venue.json、exhibitors.jsonをコピーします。

フォルダ接続中は data/events/<event_id>/ が自動作成され、events.json も更新されます。

5. イベント情報

イベント管理画面または会場Editorで以下を編集できます。

項目保存先
イベント名event.json / events.json
開始日・終了日event.json / events.json
開催時間event.json
状態event.json / events.json
都道府県・市区町村event.json / events.json。Viewの地域検索に利用します。
会場名event.json / events.json
公式URLevent.json
説明event.json / events.json

状態は upcoming（開催予定）、ongoing（開催中）、past（過去）の3種類です。

6. イベント複製・削除

定期開催や同じ会場を再利用する場合は「イベントを複製」が便利です。会場レイアウトと出店者情報も複製されます。

削除は確認後に実行されます。フォルダ接続中はイベントフォルダも削除されるため、必要なら事前にバックアップしてください。

7. 会場テンプレート

data/venue_templates.json にテンプレート一覧、data/venue_templates/ に会場JSONを保存します。

  • 新規イベント作成時にテンプレートを選択できます。
  • 「選択イベントへ適用」で既存イベントのvenue.jsonを置き換えられます。出店者情報は残るため、ブースIDとの整合性を確認してください。
  • 「現在の会場をテンプレート保存」で、選択中イベントの会場を再利用できます。
フォルダ未接続時はテンプレートJSONと venue_templates.json がダウンロードされます。テンプレートJSONは data/venue_templates/ に配置してください。

8. 過去イベント・状態の自動更新

Event Managerの「日付から状態を自動更新」を使うと、ブラウザの現在日付と開始日・終了日を比較して upcoming / ongoing / past を更新できます。フォルダ接続中は各 event.json と events.json に保存されます。

9. 会場Editorを開く

イベント管理画面の「会場レイアウト編集」を押すと、次の形式で対象イベントが開きます。

editor.html?event=sample_flower_marche_2026

v1.8以前のように config.js をイベントごとに書き換える必要はありません。

10. EditorのJSON

上部から以下の3ファイルを読み込み・保存できます。

  • event.json：イベント情報
  • venue.json：会場レイアウト
  • exhibitors.json：出店者情報

「3ファイル保存」では3ファイルを順番にダウンロードします。

12. 一括生成・整列

行数・列数・ブースサイズ・間隔・開始座標を指定してブースを一括生成できます。複数選択したブースは、左/右/上/下/中央揃え、横/縦等間隔、同サイズ化ができます。

13. 会場サイズ・背景・レイヤー

  • 会場サイズ：小1000×700、中1600×1000、大2200×1400のプリセット
  • 配置物へ自動フィット
  • 端で自動拡張
  • PNG/JPG/WebPを背景画像として読込
  • 背景・通路・設備・ブースの表示/非表示・ロック

背景画像は編集用の下敷きで、venue.jsonには埋め込みません。

14. 位置不定ブース / 出店者

v1.11では出店場所を3種類から選べます。

状態用途View
fixedA01など位置が確定した通常ブースブース位置へ移動
areaキッチンカーエリア等、エリアのみ確定同名の設備エリアを強調して移動
undecided出店場所がまだ決まっていない「出店場所未定」と表示

「＋場所未定」で非固定出店者を追加できます。ブースID / 管理ID はお気に入りや共有URLで識別するため、イベント内で重複しない値（例: K01、U01）を設定してください。

area を使う場合は、設備編集で「キッチンカーエリア」などの領域を作り、出店者の「エリア名」に同じ表示名を入力してください。

15. 出店者編集

ショップ名、カテゴリ、検索キーワード、タグ、説明、Instagram URL、ショップURL、メモを登録できます。Instagram URLは1行1URLで複数登録できます。

15. 自動保存

Editorの作業内容は event_id ごとにlocalStorageへ自動保存されます。正式データはJSONとして保存してください。

16. JSONダウンロード方式

プロジェクトフォルダ接続を使わない場合は、イベント管理画面から events.json とイベントファイルを保存し、次の場所へ配置します。

data/events.json
data/events/<event_id>/event.json
data/events/<event_id>/venue.json
data/events/<event_id>/exhibitors.json

17. GitHub Pagesへの反映

  1. ローカルファイルを編集
  2. start_local_server.bat でViewを確認
  3. GitHubへcommit / push
  4. 公開URLをCtrl+F5等で再読込して確認

18. トラブル対処

症状対処
フォルダ接続できないChrome / Edgeを使用し、プロジェクトルートを選択してください。
新しいイベントがViewに出ないdata/events.json に登録されているか確認してください。フォルダ接続中は保存時に自動更新します。
Editorで別イベントが開くURLの ?event=... を確認してください。
出店者詳細が出ない固定ブースの場合はvenue.jsonのブースIDとexhibitors.jsonのbooth_idを一致させてください。area / undecided は物理ブース不要です。
GitHubへ反映されないローカル変更をcommit / pushしたか、ブラウザキャッシュが残っていないか確認してください。
