# Marche Booth Map v1.6

1つのマルシェ会場内の出店者を、SVG会場マップと一覧から探せる静的Webアプリです。
v1.6ではView側の「お気に入り」を当日の巡回管理に使えるよう強化しました。Edit側はv1.4の機能を維持しています。

## v1.6 主な追加機能
- 「♡ 行きたい」と「✓ 行った」の2状態管理
- `すべて / 行きたい / 未訪問 / 行った` の表示切替
- 行きたい件数・訪問済み件数をヘッダー表示
- 一覧からワンタップで「行きたい」「行った」を切替
- 詳細画面からも両状態を変更可能
- マップ上に ♥ / ✓ を表示
- 訪問済みブースを専用スタイルで強調
- 「未訪問」モードで、行きたいがまだ回っていないブースだけを一覧・マップ表示
- 状態をブラウザlocalStorageへ保存
- v1.4以前の「行きたい」localStorageをv1.6へ自動移行

## 閲覧画面の基本機能
- SVG会場マップ
- ブースクリック/タップで出店者詳細

## 起動方法
### 閲覧画面
`start_local_server.bat` をダブルクリックし、`http://localhost:8000/` を開きます。

### 編集画面
`start_editor.bat` をダブルクリックし、`http://localhost:8000/editor.html` を開きます。

JSONをfetchするため、HTMLファイルの直接ダブルクリックではなくローカルHTTPサーバーを利用してください。

## 保存される個人状態
閲覧者の「行きたい」「行った」はJSONへは書き込まず、各ブラウザのlocalStorageへ保存します。そのため公開データを変更せず、来場者ごとに別々の状態を持てます。

- `marche_booth_map_favorites`: 行きたいブースID
- `marche_booth_map_visited`: 訪問済みブースID

別端末・別ブラウザ間では同期されません。

## v1.6 Instagram複数URL対応
出店者データは `instagram_urls` 配列に複数URLを保存できます。編集画面では1行1URLで入力します。互換性のため `instagram_url` には先頭URLも保存します。

```json
"instagram_urls": [
  "https://www.instagram.com/account_a/",
  "https://www.instagram.com/account_b/"
],
"instagram_url": "https://www.instagram.com/account_a/"
```
